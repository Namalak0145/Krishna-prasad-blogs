```sh
npm run check
npm run build
npm run preview
```

Open the URL printed by Astro. The production files are generated in `dist/`.

## Update and deploy

Edit `src/data/profile.ts` for project content, skills, and approved contact links. Email, LinkedIn, and phone are configured with explicitly approved public details. GitHub remains unset. Add other personal details only after explicit approval. Edit `src/pages/index.astro` for homepage copy and `src/styles/global.css` for visual styling. Detail pages are generated by `src/pages/work/[slug].astro`.

The workflow in `.github/workflows/deploy.yml` installs from the lockfile, checks TypeScript/Astro, builds static output, uploads the Pages artifact, and deploys it with minimal permissions. Enable **Settings → Pages → Source → GitHub Actions** in the intended repository. Push to `main` or run the workflow manually. Existing authenticated credentials must have repository write access.

`astro.config.mjs` derives the Pages origin and repository base path from GitHub Actions variables. User-site repositories ending in `.github.io` use `/`; other repositories use their repository prefix. For local project-path verification, set `BASE_PATH=/Krishna-prasad-blogs/` before building. Set `SITE_URL` if the hosting origin changes.

Keep resumes, extracted source documents, credentials, and private records outside this repository. Review generated output and the complete intended public history before each publication. Employer identities, exact assignments, and unapproved contact details must never be added. The initial repository had no commits.

See `HANDOFF.md` for verification and deployment status.
